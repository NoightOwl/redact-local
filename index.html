    How this app protects you

    You are viewing the hosted copy. GitHub Pages records the IP address of every visitor. For a fully private session, download this repository and open index.html from your own disk (file://), then disconnect from the network.

    Nothing leaves your device

    This app is plain HTML, CSS and JavaScript served from your own disk. Decoding, redaction and encoding all happen in your browser's local memory. There is no server, no account and no analytics.

    • All network primitives (fetch, XMLHttpRequest, WebSocket, sendBeacon, WebRTC) are replaced with throwing stubs at startup. The counter in the header shows how many calls were blocked.
    • The page ships a strict Content-Security-Policy with default-src 'none' and connect-src 'none', so no outbound connection is permitted even if code changed.
    • Nothing is written to localStorage, cookies or IndexedDB. Closing the tab destroys the image.

    Verify it yourself

    • Open DevTools → Network, then load, redact and download an image. The list stays empty.
    • Or turn off Wi-Fi / unplug the network cable — the app keeps working exactly the same.

    Metadata is stripped

    Exports are re-drawn into a fresh canvas and re-encoded, which discards EXIF, GPS coordinates, camera model, timestamps and XMP blocks. Only visible pixels survive.

    Choose the right redaction

    • Solid replaces pixels with black — irreversible. Use it for names, faces, numbers and anything that must not leak.
    • Pixelate and especially blur can sometimes be reversed by machine-learning reconstruction, particularly with small blocks or light blur.
    • Redact a generous margin: text just outside a blurred area is usually still readable.

    Operational tips for sensitive work

    • Work on a device you trust and keep the file offline until it is redacted.
    • Do not paste the same image into another tool before redacting it.
    • Redact before you crop, resize or screenshot, and share only the exported file.
